# Architecture — current state (post-R99 review, 2026-10-04)

This is an evidence-based map of who owns each canonical concept **today**. It was built from four read-only source investigations: session/signal/model, NAV/HOC/target/orders, workflow/forward/research, and a static audit (AST scan plus `audit_architecture.py --strict`).

- Citations are `file:line` at HEAD `8d6c366` plus the dirty working tree.
- Items marked **✔ re-read** were opened and confirmed directly during this review.
- All other items are cited by the investigation and were not re-read line by line.

It complements, and does not replace, the canonical `docs/CURRENT_ARCHITECTURE.md`. Where the two disagree, this file names the difference.

## Shape of the system

- **One FastAPI app.** `api/app.py` is **23,324 lines** ✔. The claim "exceeds 23,000 lines" is **true**. (An earlier count of 20,661 came from PowerShell `Measure-Object -Line`, which skips blank lines.)
  - It declares **240 routes**: 168 GET, 71 POST, 1 PATCH. There is no `include_router`.
  - It has 276 top-level functions; 35 of them are longer than 150 lines.
  - The longest inline blocks are legacy or preview logic: `daily_plan_preview` (1,006 lines), `market_scan_prediction_candidates` (790), `_compute_calibrated_rotation` (555), the replay previews, `get_workflow_status` (410), and the legacy signal → decision → order writers (`create_signals_from_candidates`, `create_decisions_from_signals`, `create_orders_from_decisions`, `create_exit_orders`, `fill_pending_paper_orders`).
  - **NAV, HOC, reassessment, proposal and forward evidence are NOT inline.** They live in owner modules.
- **Other api modules over 3,000 lines:** `portfolio_decision.py` 7,023, `workflow_state.py` 6,370, `daily_research_cycle.py` 4,404, `daily_close.py` 3,946, `information_collection.py` 3,132.
- **One UI file:** `api/ui/index.html`, about 42k lines.
- **Research:** `alpha_agent/` (r31…r99 releases, `agents_v2`, `r59` memory). It does not import `paper_trader.api` on the agents_v2/r59 path.
- **Prediction is remote only.** `config.py:98-101` sets `stock_prediction_api_url`; `engine/prediction_client.py:72-79` makes HTTP calls; no ML framework is imported in `api/` or `engine/`.

## What the strict audit enforces vs reports

`scripts/audit_architecture.py --strict` exits 0 today. It **blocks** only `duplicate_declarations`, `research_execution_terms` and the `BLOCKING_INVARIANTS` tuple (about 18,180 lines in). Module size, private imports and attributes, direct ledger references, UI wiring and concept-writer counts are **report-only**. Several of the "candidate multi-ownership" signals come from a `def`-name regex and over-count readers. So a green audit does **not** certify single ownership.
